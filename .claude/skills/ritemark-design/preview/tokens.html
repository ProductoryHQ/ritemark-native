01 — Surfaces

The neutral ladder.

Four surfaces and two hairlines. Every chrome layout is some combination of these. Grey on dark is replaced by indigo-tinted hairlines — see tokens.md for why.

--r-surface
editor, dialog body
--r-surface-muted
sidebar, titlebar, panels
--r-surface-soft
hover, secondary btn
--r-hairline
default border
--r-hairline-strong
input border
02 — Ink ladder

Four steps, never five.

Hierarchy comes from this ladder, not from adding color. If you need a fifth step, collapse something instead.

--r-ink-strong
body, H1–H3, labels
--r-ink-body
paragraph body
--r-ink-muted
meta, captions
--r-ink-faint
placeholders, counts
--r-ink-disabled
disabled state
03 — Accent

Indigo — the only one.

The single chromatic signal. Primary buttons, cursor, focus, active indicators. If you're reaching for a second accent, hierarchy can be solved another way.

--r-accent
primary btn, cursor
--r-accent-deep
hover state
--r-accent-darker
pressed state
--r-accent-soft
active row bg
--r-accent-fainter
selection highlight
04 — Semantic

Used sparingly, functionally.

No decorative green/amber/red. Success is for "saved/synced." Warning for "stale/unsaved." Error for destructive + genuine errors. Info resolves to indigo (no second "info blue").

--ritemark-success
saved, synced, pass
--ritemark-success-soft
success bg tint
--ritemark-warning
stale, caution
--ritemark-warning-soft
warning bg tint
--ritemark-error
destructive, error
--ritemark-error-soft
error bg tint
05 — Type scale

Sofia Sans in-chrome, Space Grotesk for moments.
