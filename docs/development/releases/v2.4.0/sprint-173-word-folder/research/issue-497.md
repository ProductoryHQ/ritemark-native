# #497 2.1 spike: can ChatGPT and OpenCode read a folder of Word files?

From the 2.1 shape (approved by Jarmo on 21 October 2026, a rabbit hole done first). Found by the Experience lead.

**Question.** Item 2's ready request ("Ask Claude what is here") reads a project's newest documents. 2.0 has no Word or PDF text reading for agents: that code lives only in officePreview and export. Claude reads PDFs itself, but Word needs a conversion, so ChatGPT (Codex) and OpenCode may stall on a folder full of .docx.

**Spike.** With a folder of 20 Word files and 10 PDFs, ask each of the three AIs "what is here", and record what each could read. Then pick one:
- (a) Ritemark gives agents the Markdown it already makes from .docx (the saveAsMarkdown path), for example as a tool or a read-only cache;
- (b) the request tells the AI to read only what it can open, and to say what it skipped.

Done when the shape's item 2 can promise the first look for all three AIs, or says plainly what each one sees. This comes before experience 35's ready request is built.
