## R1 · One footer for the three AIs

Use UnifiedConversationView’s shared turn projection and ActivityStatusLine’s footer, with the successful answer selected by conversation and turn ID. Reuse one rendering path for current and restored turns across Claude, Codex and ACP. Keep reaction and pending-send state local, scope it to the exact turn, and let the host validate the active conversation, eligibility and fixed mark before recording it or invoking the consent-gated tracker. Guard repeat and concurrent presses. These IDs are local only. Persist the first local thumbs-up through GuidanceStore for R3 even when the event drops.

Extend UnifiedViewProvider’s existing message dispatch with typed, validated reaction and feedback intents. Resolve the optional answer from the selected turn on the host, never from the latest answer of a different turn. Show the existing bounded answer excerpt in the inline form and use feedbackRoute and reportTransport when it is selected. Use the same shown excerpt for Copy in the new flow. Plain inline Send reuses the feedback sender and retains the draft on failure.
