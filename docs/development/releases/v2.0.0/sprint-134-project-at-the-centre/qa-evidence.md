Run on 19 October 2026, on the Mac (Apple Silicon), from `sprint-134-project-at-the-centre` (main's #462 merged in), on dev instances of this worktree launched in the background (`open -n -g`) with their own short user-data and extensions directories and their own debugging ports, driven over CDP. What could not run here, and why:
- **ChatGPT's turns, and some of Claude's.** Claude shows signed out in a fresh test profile (signing in opens a browser), so Claude ran through this Mac's own install (`ritemark.agentRuntime.preference: system`), on the Development manager's conditions: no keychain prompt at any check, `~/.codex/config.toml` byte for byte unchanged. A ChatGPT turn writes the real `~/.codex`, so ChatGPT's halves, S44's answer after Add the line and S57's live turn are covered by unit tests here and listed for Gate 2.
- **Native dialogs** (folder and file pickers, Finder, Preview, Word): they bring windows forward. What follows each was tested another way where possible, as each row says.
- **Windows** (S41, S42, and the Windows halves of S29, S52 and others): through the Development manager's Windows round.

**One harness incident** (run B): Share ▸ Show in Finder and Open in Preview on a PDF ran for real, because the wrapper meant to hold them back missed the viewer's own reference; Finder revealed the test PDF and Preview started (ended at once). The harness notes now forbid clicking anything that opens another app, stub or not. It was reported to the Development manager at once.
