## Plan
- **PR 1:** extend `generate-page-icons.mjs` to emit two generated modules from `@phosphor-icons/core`: all 1,512 path strings keyed by name, and a search index (name, tags). Widen `slideIcon` to accept any regular name or alias and return the drawn name; keep the 24 as `SLIDE_ICONS` for the pre-search view. `slideMarkup.ts` inlines only the used icons. Add a test that every generated name matches the package, and a size check in the PR text.
- **PR 2:** one `SlideIconGlyph` component that draws an inline SVG from the path module, used by `slideDivView.ts`, `SlideCanvas.tsx`, the strip, the wall and the presenter view, instead of `ui/Icon.tsx`. Chrome keeps `Icon.tsx`.
- **PR 3:** a search field in `IconGridItems` that filters the index on name, tags and aliases, renders at most a page of results, with in-use icons first, collected from the open deck's boxes.
- **PR 4:** the tooltip on the fallback badge in the editor, with a handler that opens the menu with the name preset.
- The DECKS rules (Claude's deck-writing tool and its prompt text) change in PR 1 to list names and aliases, found with `grep` for the 24's list in `src/decks/`.
