What’s new

  • A recipe chooser — the user picks the deliverable, not the technology
  • A visible pipeline: prepare → transcribe → speakers → draft, each step nameable and skippable
  • Cost and privacy shown at the decision point, in the same place as the Run button
  • Output is a finished document, with the transcript collapsed underneath as evidence

What it reuses

  • The Flows engine — a recipe is a flow; users can edit them and add their own
  • The agent runtimes for the drafting step — no new AI plumbing
  • The Ritemark editor for the result; no new editor surface
  • Closest match to the workflow you have today (Word → markdown → Ritemark), minus three apps

The risk

  • The source is hidden. If the model paraphrases a decision wrongly, nothing on screen contradicts it
  • No playback, so a quote can’t be verified before it goes to a client
  • Recipe quality becomes the product — that’s prompt work, and it never fully stops
  • Users who just want a clean transcript have to know to pick “Transcript only”
