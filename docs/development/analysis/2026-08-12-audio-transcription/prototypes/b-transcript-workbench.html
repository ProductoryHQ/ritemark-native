What’s new

  • A custom editor tab for recordings — the biggest new surface in the app
  • Audio playback synced to text: click a line to hear it, the playing line highlights
  • Speaker chips with one-click global rename, colour-coded through the transcript
  • Low-confidence highlighting (amber) on words the engine wasn’t sure about — names, jargon
  • An insights rail with timestamps that jump into the audio

Why it’s worth it

  • You can verify a quote before you send it to a client — the trust problem, solved
  • Corrections stay attached to the recording, not lost in a text file
  • Insights cite their source (12:48), so an LLM claim can be checked in two seconds
  • This is the shape a dedicated transcription tool takes — it can stand next to one

The cost

  • The heaviest build by far — custom editor, audio pipeline, waveform, a session file format
  • The transcript is no longer just a .md file until you export it
  • Playback needs decoded audio in the webview, and the webview bundle is already 7.6 MB (#107)
  • Realistically a two-phase build: Option A’s pipeline first, this surface second
