Cursor
Tab strip New Agent | Terminal at the top. Inside the textarea: ∞ Agent ▾ mode pill bottom-left, Auto 🔒 model pill bottom-right — embedded directly in the input box. Model label is always visible. Mode switching is one click, never hidden in a dropdown.
Codex (OpenAI)
Rounded input card. All controls are in the card's bottom row: permissions (lock icon), model picker, environment selector, branch picker — then send. The textarea is top-anchored, controls are footer-anchored. Branch/env pickers appear only when Codex has workspaces, so the footer grows contextually.
