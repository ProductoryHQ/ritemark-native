Margin comments

A working preview. Two ways to add a note: select text → Add comment (anchors a yellow highlight), or type /// your note at the start of a line and press Enter for a quick standalone margin note. Assign to an agent with @claude. Hover a marker to read or delete.

Q3 Product Brief

We are shipping margin comments so writers can leave notes and hand work to an AI agent without ever seeing raw markdown syntax.

Goals

The margins look healthy this quarter, but the numbers need a second look before we publish anything to the wider team.

Ship date is end of September, pending a final review from operations and a sign-off from finance.

The full report is attached below, along with the supporting spreadsheets.

What lands on disk

Portable, and stripped from every export. Two note kinds map to two storage forms — the round-trip encoding this sprint has to prove (the exact risk that deferred Sprint 72).

# anchored note (select → Add comment): a mark wraps the span
The <mark data-comment="c1">margins look healthy this quarter</mark>, but the numbers need a second look.
