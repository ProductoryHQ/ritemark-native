Claude · Sonnet 4.6
Enter queues · Shift+Enter queues and bumps to top
Proposed: input stays editable. Pressing Enter while agent runs queues the prompt. Queue shows above composer — hover any item for Edit / Promote / Delete. Turn completes → queue auto-fires.
Queue item actions
Three actions per item
Edit — click to edit the queued prompt inline. Confirm with Enter, cancel with Escape.
Promote — stop the current agent run and immediately send this queued prompt. Same as the user clicking Stop and sending manually, but one click.
Delete — remove the queued prompt. Does not affect the running turn.
Keyboard shortcuts
Enter while agent running → queue prompt
Shift+Enter → queue and promote to top
Escape while editing → cancel, restore original
Auto-send logic
When the current turn completes, the first queued item is sent automatically via useEffect on agentRunning transition true→false. Multiple items in FIFO order.
