# VS Code patches

Every change Ritemark makes to VS Code is a patch file in `patches/vscode/`, applied in number order to the `vscode`
submodule at its recorded commit. Never edit the submodule directly. Commands, the release tier and patch rules:
`CLAUDE.md` ("VS Code Patch System") and `.claude/skills/vscode-development/PATCH-RULES.md`.

When a sprint adds or changes a patch, it updates its row here in the same PR. This list lives in `docs/`, not
beside the patches: every path under `patches/` is shell-tier, so a wording fix here would otherwise block an
extension release.
