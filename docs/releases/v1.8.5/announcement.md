# Ritemark v1.8.5 — parallel agent chats

Ritemark's AI sidebar used to have one seat. Ask Claude to draft a section and you had to wait before starting anything else — or throw away context to switch tasks. That's not how people actually work with agents: you run a few things at once, glance between them, and pick up whichever one finished. v1.8.5 makes that real. The sidebar now holds **multiple independent chats**, each with its own session and history, laid out in a new **thread rail** down the right edge. Start a thread, kick off a run, open another, and switch between them — the agents keep working in the background and their replies always land in the thread that asked.

The rest of the release makes those parallel agents better citizens. The bundled runtimes were upgraded — **Claude Code 2.1.217** and **OpenCode 1.18.4** — and, crucially, re-validated against parallel sessions rather than just single-turn chats, so two threads on the same runtime behave. **Claude Opus 5** now shows up in the model picker for the heaviest work, right alongside Sonnet 5, Fable 5, and Haiku 4.5. And every agent now starts with a short **capability context** that tells it where it is — a Markdown editor with an integrated browser and a real toolset, not a bare terminal — so it reaches for Ritemark's own capabilities instead of guessing.

A couple of smaller wins round it out: the **"AI Offline" badge** now has a **Check again** link so you can re-test connectivity on demand instead of waiting out the poll, and **voice dictation** now defaults to 5-second chunks, noticeably improving accuracy for Estonian and other smaller languages. Behind the scenes, a new shell-level watchdog hardens the update path so a broken extension update can never strand your installation again.

v1.8.5 is live now on **macOS** (Apple Silicon and Intel), signed and notarized by Apple, so there are no unsigned-app warnings. Existing users get it through the in-app updater; new users can grab the DMG from the releases page. The Windows installer is being prepared and lands shortly — until then, Windows stays on v1.8.4. Open a couple of threads and let the agents run in parallel.
