# Ritemark 2.3.0 Test Checklist

> **Started on 16 November 2026** at the close-out of Sprints 159 and 160, before 2.3's release plan and candidate exist. It holds what those two sprints couldn't run, for Jarmo to test on the release candidate. The candidate's table, the Gate 1 and Gate 2 rows, Sprint 158's Not run rows and the sign-off are added when the candidate is built, as in [2.2's checklist](../v2.2.0/TEST-CHECKLIST.md).

Where the rows come from: [Sprint 159's close-out](../../development/releases/v2.3.0/sprint-159-decks-training/sprint-plan.md#close-out) and [Sprint 160's](../../development/releases/v2.3.0/sprint-160-ai-ready-day-one/sprint-plan.md#close-out).

- **Your own profile** is the main test. Rows marked **Fresh** run in a test instance with its own throwaway folders and AI homes, started as in [2.2's How to start](../v2.2.0/TEST-CHECKLIST.md#how-to-start).
- **What a row needs** is in bold at its end: **Projector** = a projector or a second display, **Clicker** = a presentation clicker, **Cloudflare** = Jarmo's Cloudflare test account, **Phone** = a real phone, **Windows** = a Windows PC, **AI** = a real signed-in AI (named), **Key** = a real API key (named), **Fresh** = a fresh profile. No mark means the candidate alone is enough.
- **The source** is in small text at the end: the sprint, its PR and the PR's number.
- Tick a row only when it passes. A row that fails gets its issue number beside it. A row not run says why and stays unticked.
