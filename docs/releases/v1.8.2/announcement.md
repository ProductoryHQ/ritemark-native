# Ritemark v1.8.2 — now on Windows

Ritemark has always been at home on the Mac. As of v1.8.2, it's at home on Windows too. Until now, a default Windows 11 machine would simply refuse to install Ritemark — Windows couldn't confirm who published the app and blocked it outright. That wall is gone: the whole Windows app is now properly signed, so it installs like any trusted program, no scary warnings, no "run anyway" detours. Local-first, distraction-free markdown editing — the way it's meant to be — now works out of the box on both platforms.

This release fixes the rough edges that made Windows feel second-class. If you keep your notes in OneDrive or SharePoint, a file that hasn't finished syncing no longer fails with a cryptic error — Ritemark tells you exactly what to do to open it. The New File and New Folder buttons in the File Browser now stay put instead of hiding. And under the hood, we repackaged how the app is built, so it's a smaller download and boots more cleanly, with fewer of the occasional glitches that used to creep in.

macOS (Apple Silicon and Intel) is available to download right now; the signed Windows installer follows shortly. Both Mac builds are signed and notarized by Apple, so there are no Gatekeeper warnings. Grab the latest from the releases page — and if you've been waiting to run Ritemark on your PC, this is the one.
