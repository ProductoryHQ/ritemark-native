## Blog-post intro (≤1200 chars)

![Agent Library — discovered .claude/ agents and skills in one panel](./screenshots/1-6-0-agent-management-fullscreen.png)

> **Ritemark v1.6.0 ships the Agent Library — and the app finally looks like itself.**
>
> If you write agents or skills for Claude Code, you know the problem: they live in hidden `.claude/` folders and they're invisible until you remember to invoke them. You accumulate them across projects, you write the same one twice because you forgot the first version existed, and reviewing what you've got means a `find` command and a lot of scrolling.
>
> v1.6.0 puts an end to that. The new **Agent Library** is a dedicated activity-bar entry that auto-discovers every agent, skill, and slash command in your workspace and your user-scope `~/.claude/` directory, groups them by scope, and opens the source `.md` file with one click. The files stay the source of truth — the panel just makes them visible.
>
> This release also closes the visual gap between Ritemark and "VS Code with a theme on top." Primary navigation icons are now Phosphor instead of Codicons, the activity bar is redrawn with a rounded active-state indicator, and Ritemark Dark ships as a first-class theme. There's also an inline Table of Contents rail for long documents and a CSV → Excel encoding fix that finally makes Estonian (and other UTF-8) characters survive the trip to Mac Excel.

(1187 characters)
