## LinkedIn (longer, professional tone)

**Ritemark v1.8.3 is here — and it introduces Comments.**

Writing is rarely one clean pass. You leave yourself notes, flag a paragraph to rework, ask a question about a sentence you'll return to. Until now, Ritemark had no way to do that without cluttering the prose.

v1.8.3 fixes that with **Comments**:
- Select any text and click **Comment** for a highlighted anchor plus a margin note — the familiar Google-Docs model.
- Type `///` for a quick standalone note in the right margin.
- Comments save into the Markdown file itself, so they persist across saves and reopens.

Comments are also the shortest path to Ritemark's AI. Mention `@claude`, `@codex`, or `@opencode` in a comment and a **Send to AI** button relays that exact passage — and your note — into the AI sidebar. No copying paragraphs, no re-explaining context.

Rounding out the release: **GPT-5.6** models now appear in the Codex picker, new chats stay as separate History sessions again, and attachment chips are visible for text and Markdown files.

Fully cross-platform and live now — macOS (Apple Silicon + Intel, notarized) and Windows (x64, code-signed).
