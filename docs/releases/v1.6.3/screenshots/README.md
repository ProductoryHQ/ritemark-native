# v1.6.3 Screenshots

Add screenshots here for the v1.6.3 release materials and the user support docs that explain the new agentic workflow.

## What this release needs to show

v1.6.3 is about a more complete agentic experience:

- one conversation can switch runtimes per turn
- the Agent Library can create, fork, and launch helpers
- `AGENTS.md` and `.agents/` are first-class discovery sources
- helper rows now have clearer visual identity and actions

## File naming convention

Use:

`v1-6-3-{surface}-{state}.png`

Examples:

- `v1-6-3-ai-sidebar-runtime-switch.png`
- `v1-6-3-agent-library-launch-chat.png`
- `v1-6-3-agent-library-new-helper-modal.png`

## Recommended capture setup

- Use the v1.6.3 build
- Open a workspace that contains both `.claude/` and `.agents/`
- Have at least one agent and one skill available in the library
- Make sure Claude and Codex are both signed in so runtime switching can be shown
- Keep the window size consistent across shots
