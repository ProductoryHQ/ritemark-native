## Listing delta

Description and screenshots unchanged.

What's new:

> Ritemark 1.14 brings a task board to every project folder. Click Tasks to see what waits on you, add a task, and give it to Claude, Codex or OpenCode. The agent works in its own conversation while you keep writing, then reports back, and you mark it done or ask for changes.
>
> Voice dictation and on-device transcription now work on Windows. Your voice is turned into text on your own PC: nothing is uploaded, and after a one-time download it works offline.
>
> Also new: the browser's Recent list keeps every page you visit, with titles; Haiku 5.5 in the Claude model menu; GPT-6.1 Sol as the default Codex model; and updated built-in agents (Claude Code 2.1.296, Codex 0.162.1, OpenCode 1.19.0).
