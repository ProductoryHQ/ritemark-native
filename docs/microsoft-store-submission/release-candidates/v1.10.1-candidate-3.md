### Observations

- **Stale version after an earlier manual upgrade — not reproduced.** Before this audit, Apps & Features showed `Ritemark 1.10.0` after 1.10.1 had been installed over it. A logged upgrade with the Store parameters updated the entry to `1.10.1` correctly. The earlier upgrade was run outside this test and without a log, so its cause is unknown. Store installs go through the Store parameters, so this does not affect certification.
- **First-run layout on a brand-new profile.** On a fresh profile, what a new user or reviewer sees, the right side bar can open on a terminal with Ritemark AI hidden in its "…" menu, and opening a folder shows an empty "CHAT" sidebar. Not deterministic; 2 of 3 fresh launches. This does not block installation or function, but it is the reviewer's first impression. Tracked in [#276](https://github.com/ProductoryHQ/ritemark-native/issues/276).
- The status-bar word count stayed at 121 after the agent added a section (minor).
