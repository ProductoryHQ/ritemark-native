## Exact certification notes for the draft

```text
Ritemark 1.11.0 addresses the four findings in the certification report completed 15 September 2026.

Pricing is classified as Freemium because optional AI features may require the user's own third-party provider account, subscription, or API credits. Ritemark itself does not sell an in-app subscription.

To test inappropriate AI-output reporting:
1. Launch Ritemark and click “Report AI issue” in the status bar, or open AI Information from the AI sidebar and choose the same action.
2. Enter report text. The preview contains only the user-entered text plus app version, platform, and timestamp.
3. “Open email” prepares a message to info@productory.eu. If no mail handler is configured, the dialog keeps the address and full report visible and offers “Copy report”. Ritemark does not claim that a message was sent.

The Source Control empty state no longer offers or links to a Git download. When Git is absent it only explains that Git is required. Installed Git and normal Source Control functionality remain unchanged.

The English (United Kingdom) 2:3 poster art (reported as StoreLogo2) has been replaced with artwork showing the Windows application only.

Package URL: https://getritemark.com/windows/v1.11.0/Ritemark-Setup.exe
SHA-256: 0ebda5016e432b2f039613f74665343220006e39e7749ddb76d285d0a87b932b
Architecture: x64
Silent install: /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- /CURRENTUSER

Local document editing requires no account and works offline. Optional AI features require network access and the user's own supported provider credentials. Audio transcription is not available in this Windows version.
```
