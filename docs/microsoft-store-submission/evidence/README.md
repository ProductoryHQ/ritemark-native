# Evidence

This directory stores reusable Microsoft Store preparation evidence that does not belong in a single release folder.

- `account-onboarding/` contains company-verification evidence and a dated onboarding status note.
- `url-check-2026-09-01.md` records the external URL state used to prepare the worksheet.

Do not store passwords, API keys, recovery codes, identity-document scans, or unnecessary personal information here. **This repository is periodically public and Git history is permanent**, so also keep out documents that merely *contain* personal contact details — including official register extracts, which list the company's registered telephone number. Record such a document by name, source, date, and SHA-256 instead of committing it. The company registry extract is public business evidence and must not be used as a Store listing asset.
