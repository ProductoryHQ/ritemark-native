# AI Assistant — removed in v1.7.2

> **This feature no longer ships.** The **Ritemark Agent** (also called the Legacy Agent) — a direct
> OpenAI chat runtime with rephrase, find-and-replace, and insert tools, plus document search (RAG) —
> was removed in v1.7.2 (Sprint 74).

The AI sidebar now offers three agents: **Claude Code**, **Codex**, and **OpenCode** (added in v1.7.3).

- For the current AI sidebar, see **[AI Agents](ai-agents.md)**.
- To configure AI, see **[Set Up AI](../setup-ai.md)**.
- The OpenAI API key is still used by **[Flows](flows.md)** (LLM Prompt and Image Generation nodes).

The original Ritemark Agent documentation is preserved for historical reference at
**[archive/ai-assistant.md](archive/ai-assistant.md)**.
