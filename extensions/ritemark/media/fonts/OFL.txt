Fonts in media/fonts/, the six fonts a deck's theme can use (Sprint 162).

Each is a variable woff2 file (its weight axis only, upright), in two subsets:
latin and latin-ext. Each copyright line below is the one in the font file's
own name table. A published deck page carries the files of the fonts its theme
uses, as the licence allows (OFL 1.1, section 2: bundled with software).
