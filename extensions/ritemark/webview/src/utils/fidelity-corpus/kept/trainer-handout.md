# Workshop: running a good retrospective

## Before the session

- [x] Book a room for 90 minutes
- [ ] Print the timeline sheet
- [ ] Bring sticky notes

## The five steps

1. Set the stage
2. Gather data
3. Generate insights
4. Decide what to do
5. Close the retrospective
