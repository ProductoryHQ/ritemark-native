# 08. Code Ownership Areas

## Objective

Make sure important parts of the system have clear technical ownership.

## Initial Ownership Areas

- VS Code shell.
- Extension activation.
- Webview and editor.
- Flows.
- Release and build.
- Security-sensitive IPC.
- Persistence and storage.

## First Implementation

- Map each area to paths.
- Assign a primary owner or reviewer.
- Define when an owner must review a change.
- Keep ownership lightweight and easy to update.

## Starting Checklist

- [ ] Create ownership map.
- [ ] Link areas to directories.
- [ ] Assign current owners or temporary reviewers.
- [ ] Define sensitive ownership areas.
- [ ] Review map once per sprint.

## Automation Later

- Changed-path reviewer suggestions.
- Sensitive-area ownership alerts.
- Ownership coverage report.
