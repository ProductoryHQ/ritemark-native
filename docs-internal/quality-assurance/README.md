# Quality Assurance

This folder defines Ritemark's quality assurance operating model. It starts with company routines and implementation plans before automation design, so tooling can support real quality practices instead of producing unfocused reports.

## Documents

- [Strategy Overview](./strategy-overview.md)
- [Implementation Plan Index](./implementation-plans/README.md)

## Current Principle

Automation should amplify an agreed quality routine. The first version of this plan therefore focuses on what the company should repeatedly do, who the work is for, and how findings become decisions.
